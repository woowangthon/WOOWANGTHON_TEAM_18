## Lessons

- **Emptying Tailwind's defaults is what keeps the "AI look" out.** Do it in `@theme` with `--color-*: initial` and prove it by generating a class that must not exist.
- **Variables + `@theme inline` give dark mode without `dark:` classes**, but the three lists (light, dark, alias) can drift; keep a test that checks they stay equal.
- **Sample data on a page is still sample data.** The style guide's fake projects needed `SAMPLE(<id>)` markers and `ai-scope.md` rows even though the page is temporary. *(Pitfalls candidate)*
- **Scrollable regions need a name and keyboard focus**; `role="log"` is a live region and is wrong for static text.
- **Korean UI needs `word-break: keep-all`.** The browser default breaks between any two syllables, so short labels split as `프로젝/트` and `머/지`. Check by looking at a 390px render, not only desktop.
- **Never assume a font has a feature; measure it.** `tabular-nums` was applied for a whole review cycle and did nothing. Render `1111` and `0000` and compare widths.
- **Measure before preloading.** On a narrow link, preloading a second 0.7MB font delayed first paint by ~0.3s and gained nothing. A third-party stylesheet that blocks rendering is the bigger risk, and it only shows when you delay that host.
- **Vite dev on a WSL `/mnt/c` checkout can serve stale code**: file-change events do not arrive, so edits did not show up until the dev server was restarted (a measurement run looked "unchanged"). Restart it, or use `server.watch.usePolling`, before judging a change. *(Pitfalls candidate, WSL only)*
- **`selectors` in `eslint-plugin-better-tailwindcss` replaces the default list.** With only `className` the `variants` objects were not checked; a probe file with `bg-indigo-500` inside a `variants` object proved it before the rule was trusted.
- Mutation testing was not run: no mutation tool is chosen yet ([`docs/conventions.md`](../../docs/conventions.md) §6).
- **`opacity` on a disabled control fades the text with its background.** The contrast stays near 1:1 whatever the colors were; use dedicated tokens for the disabled state.
- **A tone step below about 1.08:1 is not a step.** `#fafafa` on `#ffffff` (1.04:1) looked intended in a spec and invisible on screen. Pin the minimum in a test.
- **A valid arbitrary class is not an unknown class.** `no-unknown-classes` cannot enforce "no values outside the tokens"; that needs `no-restricted-classes` with a pattern, and a probe file to prove it. *(Pitfalls candidate)*
