## Lessons

- **Arm the undo before a change that can cut remote access.** `systemd-run --on-active=150 <undo>`, then apply, reconnect from outside, then `systemctl stop <unit>.timer`. Used for netplan, sshd and both ufw switches; none needed it, but a mistake would have cost a trip to the club room. *(Pitfalls candidate)*
- **cloud-init can rename the host back on reboot.** With `preserve_hostname: false` and the `update_hostname` module, add a `cloud.cfg.d` drop-in with `preserve_hostname: true` before relying on `hostnamectl`.
- **Add addresses in a second netplan file instead of editing `50-cloud-init.yaml`.** Netplan merges the address lists; check the merged result with `netplan generate` and the generated networkd file before `netplan apply`.
- **Ubuntu minimized server has no `ping` or `nmcli`.** Test reachability with `timeout 3 bash -c '</dev/tcp/<ip>/22'` and the internet with `curl -4 -sSI -m 8 https://tailscale.com`. Do not use 1.1.1.1 as a test target: the school network blocks it.
- **ufw cannot allow by domain.** Registries, package mirrors and Tailscale sit on CDNs, so outbound filtering is by port, not by host.
- **Edit the draw.io model embedded in the SVG, not an old generator copy.** The repo SVGs had moved past the generator scripts in later PRs. Pull the `content` attribute out as a `.drawio`, change cells by id, and re-export with `draw.io -x -f svg -e` so the picture and the embedded model stay the same.
- **`--flannel-iface` does not choose the address.** Flannel takes the first IPv4 address on the card as the VXLAN source; with a school address first, VXLAN carries the school source and the firewall drops it. With all nodes on one switch, `host-gw` + `node-external-ip` + `flannel-external-ip` makes the node address the next hop. Check both the `public-ip` annotation and `ip -d link show flannel.1`. *(Pitfalls candidate)*
- **hostPort and NodePort bypass ufw INPUT.** They are DNATed and go through FORWARD. Disable ServiceLB when the tunnel is the entry and set kube-proxy `nodeport-addresses` to the node network. *(Pitfalls candidate)*
- **New Pods lose their first packets to ufw's routed deny** until kube-router installs their chain; `ufw route allow` for the Pod CIDR fixes it, and NetworkPolicy still runs before ufw.
- **ufw parses `in`/`out` inside a comment** as direction keywords on `route` rules ("Invalid interface clause"). Keep those words out of comments.
- **`pkill -f` matches its own SSH command line.** A pattern that also appears in the `bash -c` string kills the session; kill by PID.
- **k3s leaves `NodeHosts` empty when its CoreDNS is disabled.** A CoreDNS copied from k3s needs the key, or the Pod never mounts its ConfigMap.
- **zsh does not word-split unquoted variables.** A `for pair in "host ip"; set -- $pair` loop silently passed the whole string as one argument; run such loops in bash.
