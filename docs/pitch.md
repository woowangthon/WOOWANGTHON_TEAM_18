# 발표와 시연 영상

> 발표 PDF·시연 영상의 설계도. 규칙(10분, 5분 영상, 자막·배속 규칙)은 [`hackathon.md`](hackathon.md).
> 사전 평가 80점은 PDF와 영상으로, 현장 20점(전달력 10 · 설득력 5 · 질의응답 5)은 본선에서 받는다.

## 2. 시연 영상 콘티 (5분 이내)

[`SRS.md`](SRS.md) §5 데모 시나리오를 따라간다. 실행 생략·결과 조작 금지 — 기다리는 구간은 배속으로 줄이고 우측 상단에 표시한다.

| # | 시간 | 화면 | 보여줄 것 (FR) | 배속 | 모킹/샘플 표시 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0:00 | | | 1x | |
| 2 | | | | | |

- 일반 설명 자막 금지 → 설명은 내레이션으로.
- `MOCK`·`SAMPLE`이 화면에 나오는 구간은 `모킹`/`샘플` 표시 ([`ai-scope.md`](ai-scope.md) §3의 "시연에 나오나" 열).
- 업로드 후 로그아웃 상태에서 재생되는지 확인.
