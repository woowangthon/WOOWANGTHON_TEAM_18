# ADR — 아키텍처 결정 기록

**되돌리기 비싼 결정만** 남긴다: 스택, 데이터 저장소, AI 모델·외부 API, FE/BE/AI 경계, 배포처.
라이브러리 하나, 폴더 이름 같은 건 ADR 감이 아니다 — 커밋 메시지로 충분하다.

## 규칙

- [`000-template.md`](000-template.md)를 복사해 `NNN-<slug>.md`로 만든다. 번호는 다음 숫자.
- **1페이지.** 대안을 최소 하나 적는다. 대안이 없었다면 결정이 아니라 사실이다.
- 결정이 바뀌면 원래 ADR은 지우지 않고 상태를 `대체됨 (→ NNN)`으로 바꾼 뒤 새 ADR을 쓴다.
- 아래 인덱스 표에 한 줄 추가. [`design.md`](../design.md)에 영향이 있으면 같은 PR에서 고친다.
- 심사 Q&A의 "왜 이 기술을 썼나요?"에 대한 답이 여기 있다. 발표 전 한 번 훑는다.
