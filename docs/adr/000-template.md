# ADR-NNN: 결정을 한 문장으로

- **상태**: 제안됨 / 채택됨 / 대체됨 (→ NNN)
- **날짜**: YYYY-MM-DD
- **결정자**: 이름들
- **관련**: SRS `FR-xx`, 다른 ADR

## 맥락

무엇 때문에 지금 결정해야 하는가. 해커톤 제약(마감, 무료 티어, 팀 경험, 심사 기준)이 있으면 적는다.

## 결정

무엇을 하기로 했는가. 2–4문장.
