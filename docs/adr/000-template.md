# ADR-NNN: 결정을 한 문장으로

- **상태**: 유효 / 유효 (일부 대체: <항목> → NNN) / 대체됨 (→ NNN)
- **날짜**: YYYY-MM-DD
- **결정자**: 회의에 참석해 정한 사람들
- **관련**: SRS `FR-NNN`, 다른 ADR
- **대체**: ADR-NNN 또는 ADR-NNN의 <항목> (선행 ADR을 바꾸는 경우에만. 아니면 줄을 지운다)

## 맥락

무엇 때문에 지금 결정해야 하는가. 해커톤 제약(마감, 무료 티어, 팀 경험, 심사 기준)이 있으면 적는다. 선행 ADR을 대체한다면 무엇이 왜 바뀌었는지 여기에 적는다.

## 결정

무엇을 하기로 했는가. 2–4문장. 선행 ADR을 전체 대체하면 유지되는 부분도 다시 적어 이 문서만 읽어도 현재 결정이 보이게 하고, 일부 대체면 바뀐 항목만 적는다(나머지는 선행 ADR에서 그대로 유효).
