# 정해야 할 것

[ADR-002](adr/002-system-architecture.md)에서 아직 정하지 않은 항목. 되돌리기 비싼 것은 ADR로, 나머지는 [`architecture.md`](architecture.md)·[`design.md`](design.md)·[`SRS.md`](SRS.md)에 반영하고 여기서 지운다. 번호는 ADR이 참조하므로 바꾸지 않는다.
