## 문항별 결과

### 1. 개발한 프로젝트를 실제 서비스로 배포한 경험이 있나요?

| 답 | 응답 | 비율 |
| --- | --- | --- |
| 예 | 22명 | 59% |
| 배포한 적은 없지만 배포하고 싶음 | 8명 | 22% |
| 아니오 | 7명 | 19% |

배포 경험이 없는 사람은 15명(41%)이다.

### 2. 배포한 경험이 있다면, 지금도 배포되어 있나요?

배포 경험이 있는 22명 기준이다.

| 답 | 응답 | 비율 |
| --- | --- | --- |
| 프로젝트 과목에서 배포 후 현재는 운영 종료 | 9명 | 41% |
| 네 (지금도 운영 중) | 7명 | 32% |
| 아니요 | 5명 | 23% |
| 서버 문제로 일시 중단 | 1명 | 5% |

> 배포 경험이 없다고 답한 2명이 이 문항에 "운영 종료"로 답해서, 전체 응답으로 세면 "운영 종료"는 11명이다. 이 문서와 SRS는 배포 경험자 22명 기준(9명)을 쓴다.

### 3. 프로젝트 배포 및 운영 과정에서 걱정되는 점은 무엇인가요? (복수 선택)

| 답 | 응답 | 비율 |
| --- | --- | --- |
| 지속적인 유지보수 및 관리가 부담되어서 | 25명 | 68% |
| 요금이 예상보다 많이 나올까 봐 | 23명 | 62% |
| 무료 플랜의 한도, 기간이 끝나면 비용을 지불해야 해서 | 18명 | 49% |
| 보안 취약점으로 인한 개인정보, 데이터 유출이 걱정되어서 | 16명 | 43% |
| 배포 과정에서 직면하는 비숙련된 시스템 사용 및 대처에 관한 문제 | 1명 | 3% |
| 직접 입력 | 1명 | 3% |

비용 관련(요금 또는 무료 한도 중 하나 이상)은 29명(78%)이다.

### 4. 배포 및 운영과 관련해 어떤 도움이 있으면 좋겠나요? (복수 선택)

| 답 | 응답 | 비율 |
| --- | --- | --- |

| 모니터링 및 장애 대응 방법 | 14명 | 38% |

### 5. 학교에 남는 컴퓨터로 학생 프로젝트를 무료로 띄워 주고, AI가 배포 전 보안 점검과 배포 후 모니터링을 해 주는 서비스가 있다면 쓰실 것 같나요?

| 답 | 응답 | 비율 |
| --- | --- | --- |
| 사용하고 싶다 | 26명 | 70% |
| 당장은 아니더라도 기회가 된다면 사용할 것 같다 | 11명 | 30% |

> 이 문항은 "배포 전 AI 보안 점검"을 포함해 물었다. 그 기능은 이후 구현 범위에서 뺐다(2026-11-11, [`ai-scope.md`](ai-scope.md) §2).

## 직접 입력 응답

- 걱정되는 점: "배포에 대한 지식이 없어요. 지식을 쌓을 시간은 없고... 강의는 비싸요. 믿을만한 기초 가이드가 있었으면 좋겠어요." (배포 경험 없음)
- 바라는 도움: "automatic deploy from ci/cd to maintenance for free"
- 바라는 도움: "정적 페이지는 쉽고 무료한도에서 충분히 배포가능한데 백엔드나 서버를 붙였을때 가장 효율적이고 무료의 한도안에서 좋은 방법"

## 문제와 연결

README Summary의 "어떤 문제" 세 가지에 대응하는 숫자다.

| 문제 | 근거 |
| --- | --- |
| 처음 배포가 어렵다 | 배포 경험이 없는 사람이 15명(41%). 비숙련 문제를 고른 사람 1명, 기초 가이드를 바란 서술 응답 1명. **"배포가 어렵다"를 직접 묻는 문항은 없어서 직접 근거는 작다** |
| 배포한 뒤가 더 어렵다 | 유지보수·관리 부담 25명(68%). 배포해 본 22명 중 지금도 운영 중인 사람은 7명(32%), 과목 종료와 함께 내려간 사람은 9명(41%). 모니터링·장애 대응 도움을 바란 사람 14명(38%) |
| 계속 운영하려면 비용이 든다 | 비용 걱정 29명(78%), 비용 관리·무료 배포 방법을 바란 사람 28명(76%) |

## 한계

- 응답 37명, 한 학부, 며칠간의 설문이다. 전체 학생을 대표하지 않는다.
- "배포가 어렵다"에 해당하는 선택지가 걱정되는 점(3번)에 하나뿐이라, 그 항목의 응답 수는 작게 나올 수밖에 없다. 처음 배포의 어려움은 이 설문으로 크기를 말하기 어렵다.
- 같은 학부 학생이 응답해서 서비스에 호의적일 수 있다. 5번의 사용 의향은 실제 이용을 뜻하지 않는다.
